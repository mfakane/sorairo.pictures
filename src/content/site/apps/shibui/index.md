余白と文字の使い分けで、見る順番や操作のまとまりを伝えるミニマルなデザインシステムです。読み物と操作ツールのそれぞれに向けた見本があり、CSS は特定のフレームワークに依存しません。ライト・ダーク表示は OS の設定に追従します。

実装に使える CSS トークン・コンポーネントに加え、コーディングエージェントが同じ原則で UI を作ったり見直したりするためのスキルを公開しています。

[デザイン原則と実装例](https://shibui.pages.dev/) · [GitHub](https://github.com/mfakane/shibui)
