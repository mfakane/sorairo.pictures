Markdown から変換した HTML を、論文や技術報告のように組版する CSS テーマです。広い画面では二段組、狭い画面では一段組になり、図表・コード・数式も本文と一緒に配置できます。

ブラウザ用の表示と A4 印刷向けのスタイルを備えています。特定の Markdown 変換器や JavaScript に依存せず、既存の HTML に CSS を追加して使えます。

[組版サンプル](https://mfakane.github.io/definitely-reviewed/) · [GitHub](https://github.com/mfakane/definitely-reviewed)
