F# Compiler Services (FCS) を WebAssembly 上で動かすためのプロジェクトです。  
Browser WASM と WASI の両方に対応し、F# コードの解析、シンボル情報の取得、実行を同じ API から扱えます。

ブラウザ版 Playground では、Web ブラウザ上で F# コードを入力して FCS の動作を試すことができます。

[GitHub](https://github.com/mfakane/wasm-fcs)
